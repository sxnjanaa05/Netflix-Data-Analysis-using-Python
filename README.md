# 🎬 Netflix Data Analysis using Python

A complete **Exploratory Data Analysis (EDA)** project on the Netflix Titles dataset using **Python, Pandas, Matplotlib, and Seaborn**. This project explores Netflix's content library by analyzing movies, TV shows, genres, directors, countries, release trends, and content ratings through data cleaning and visualizations.

---

## 📌 Project Overview

Netflix hosts thousands of movies and TV shows from different countries and genres. This project performs data preprocessing and exploratory data analysis to uncover meaningful insights about Netflix's content library.

The project demonstrates a complete EDA workflow including:

- Data loading
- Data cleaning
- Handling missing values
- Removing duplicates
- Exploratory Data Analysis (EDA)
- Data visualization
- Business insights

---

## 🎯 Objectives

- Explore the Netflix Titles dataset.

# 📊 Business Insights

Some important insights from the analysis include:

- Movies significantly outnumber TV Shows on Netflix.
- The United States contributes the largest amount of content.
- Drama and International Movies are among the most popular genres.
- Several directors have contributed multiple Netflix titles.
- Netflix's content library has expanded rapidly in recent years.
- Content is available across a wide range of audience ratings.
